# Telegram Learning Mini App (100% Bepul)

Rasmdagi ta'lim va AI assistent interfeysi asosida yaratilgan **Telegram Mini App**.

## 🚀 Xususiyatlari:
1. **1-Ekran (Roadmap & Streak):** Haftalik kalendar, yuguruvchi illyustratsiya, darslar ro'yxati.
2. **2-Ekran (Dashboard):** Foydalanuvchi ma'lumotlari, qidiruv, Motion Lab featured kartochkasi, toifalar (Logic, Visual, Focus), rang-barang kurslar.
3. **3-Ekran (AI Assistant & Voice):** Ovoz to'lqini (Sound orb), **100% BEPUL Web Speech API** (mikrofon orqali ovozdan matnga), Groq Llama-3.3 integratsiyasi, interaktiv Roadmap Gantt chizmasi.
4. **Haptic Feedback:** Tugmalar bosilganda Telegram tebranish effekti.
5. **0 Xarajat:** API kalitlarsiz ham ishlaydi, xohlasangiz bepul Groq kalitini sozlamalardan kiritishingiz mumkin.

## 🛠 Ishga tushirish (Lokalda):
```bash
cd telegram-learning-app
npm run dev
```
Brauzerda: `http://localhost:5173/`

1. Ushbu loyihani GitHub'ga yuklang.
